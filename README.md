# Student Grade Tracker

A Java console application for managing student records and marks.

## Features
- Add students
- View all students
- Calculate average marks
- Find highest marks
- Find lowest marks
- Search students
- Delete students
- Update marks
- Save student data in a file

## Technologies
- Java
- ArrayList
- Scanner
- File Handling

## How to Run

Compile:

```bash
javac StudentGradeTracker.java
```

Run:

```bash
java StudentGradeTracker
```
